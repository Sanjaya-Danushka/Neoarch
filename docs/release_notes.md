NeoArch v1.0-beta - Initial Release

## What's New

### ✨ Features
- Modern graphical package manager for Arch Linux
- Multi-source package support (pacman, AUR, Flatpak, npm)
- Intuitive PyQt6-based interface
- Plugin system for extensibility
- Bundle management for easy deployments
- Dark theme UI

### 🔧 Improvements
- Professional project structure
- Comprehensive documentation
- Security-focused design
- Free software under GPL-3.0-or-later

### 📦 Installation
- Available on AUR: `yay -S neoarch-git`
- Direct source installation available

### 🐛 Bug Fixes
- Fixed toolbar positioning issues
- Resolved loading spinner layout problems
- Improved console toggle functionality
- Enhanced plugin icon handling

### 📚 Documentation
- Complete README with installation guides
- CLI arguments documentation
- Contributing guidelines
- Security policy
- Code of conduct

## Installation

```bash
# From AUR (recommended)
yay -S neoarch-git

# Or from source
git clone https://github.com/Sanjaya-Danushka/Neoarch.git
cd Neoarch
python aurora_home.py
```
